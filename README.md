# Mapas offline de GPX Group Tracker

Mapas en formato [Mapsforge](https://github.com/mapsforge/mapsforge) que descarga la app GPX Group Tracker
(NandoSoft) para usarlos sin conexión. Además de lo habitual, llevan algunas etiquetas de OpenStreetMap que los
mapas de serie no traen: acceso para vehículos y motos (`access`, `motor_vehicle`, `motorcycle`, `vehicle`), firme
(`surface`) y estado (`smoothness`).

Cada versión está en una *release* con fecha (por ejemplo `v2026-11`):

| Archivo | Zona |
|---|---|
| `spain.map` | España |
| `andorra.map` | Andorra |
| `portugal.map` | Portugal |
| `aquitaine.map` | Aquitania (Francia) |
| `midi-pyrenees.map` | Mediodía-Pirineos (Francia) |
| `languedoc-roussillon.map` | Languedoc-Rosellón (Francia) |

y la señalización de cada lugar.
